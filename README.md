# SIPesantren
# 🕌 SIM LPKI - Sistem Informasi Manajemen Lembaga Pendidikan Keagamaan Islam

*(Pendataan Resmi di Lingkungan RMI PCNU Kabupaten Magelang)*

Aplikasi berbasis web ini dikembangkan menggunakan **Python (Streamlit)** dan **SQLite** untuk mendukung proses pendataan, pengelolaan data kelembagaan, serta portofolio digital secara terstruktur dan terpadu di lingkungan lembaga **RMI PCNU (Rabithah Ma'ahid Islamiyah - Pengurus Cabang Nahdlatul Ulama) Kabupaten Magelang**.

---

## ✨ Fitur Utama Aplikasi

1. **Dashboard Rekapitulasi**: Ringkasan data kuantitatif seluruh satuan pendidikan, pengajar, santri, dan inventaris secara real-time.
2. **Profil & Legalitas Lembaga**: Manajemen informasi resmi lembaga, nomor statistik, jenis lembaga (Pesantren, Madrasah Diniyah, TPQ, RTQ, TQA, PAUDQu), alamat, pimpinan, hingga legalitas hukum.
3. **Manajemen Satuan Pendidikan Formal**: Pendataan unit pendidikan formal mulai dari jenjang TK/RA, SD/MI, SMP/MTs, SMA/SMK/MA, hingga Perguruan Tinggi lengkap dengan fitur impor Excel.
4. **Manajemen Data Pengajar**: Pengelolaan data guru/ustadz, bidang pengajaran, kontak, serta fitur input massal via Excel dan CRUD (Edit/Hapus).
5. **Manajemen Data Santri**: Pendataan lengkap warga belajar/santri, kelas, kamar/asrama, hingga informasi wali murid beserta opsi unduh/impor template Excel.
6. **Manajemen Sarana & Prasarana (Sarpras)**: Pencatatan inventaris fisik lembaga beserta kondisi barang (Baik, Rusak Ringan, Rusak Berat).
7. **Galeri & Dokumentasi Visual**: Modul dokumentasi foto untuk Papan Nama Lembaga, Gedung/Asrama, Ruang Belajar, hingga Kegiatan Pembelajaran KBM.
8. **Cetak Portofolio Word (.docx)**: Fitur otomatisasi pembuatan laporan dokumen resmi profil dan rekapitulasi data lembaga siap cetak.

---

## 🛠️ Tech Stack

* **Bahasa Pemrograman**: Python 3.x
* **Framework Antarmuka**: Streamlit
* **Penyimpanan Data**: SQLite (`lpki.db`)
* **Pengolahan Data & Laporan**: Pandas, Openpyxl, python-docx

---


## 🎨 Kustomisasi Tema

Aplikasi ini dikustomisasi menggunakan tema warna khas keagamaan (nuansa **Hijau Pesantren** pada sidebar dan latar belakang hijau muda yang lembut) dengan tombol aksi utama bernuansa **Biru** serta kolom input berwarna abu-abu yang nyaman di mata untuk penggunaan jangka panjang.
